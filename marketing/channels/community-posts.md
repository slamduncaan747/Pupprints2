## 4. Facebook breed groups (10)

**Before posting in any group:**
1. **Read the group rules** (About → Group rules).
2. Most breed groups **ban** self-promotion outright, or only allow it in a weekly "Promo Saturday" or "Small business" thread. Post there.
3. If promotion isn't mentioned, **message an admin first** with this note: "Hi! I run a small dog-portrait studio and would love to paint 20 free portraits for members. No purchase needed. Okay to post?"
4. Post **one** group per breed. Reply to every comment.
5. **Paint what you promise, within 24 hours.**
6. Never post the same text in more than ~3 groups a day (Facebook flags that as spam).

**Find groups:** search Facebook → Groups, using the terms below. Pick active groups (multiple posts a day) with 5K–200K members.

**Mechanic:** Facebook group comments accept photos, which makes this the cleanest "comment your dog" loop we have. Owners post their own photo, so consent is built in. Make their portraits with Admin → Gifts and send them by Messenger.
